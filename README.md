# KayaContent AI — MVP V1

Prototype web app untuk workflow affiliate content.

## Jalankan
1. Install Node.js 20+.
2. Buka folder projek dalam terminal.
3. Jalankan:
   npm install
   npm run dev
4. Buka URL yang Vite beri.

## Status
Ini prototype UI + local demo generator. Ia belum menyambungkan AI API atau scraper produk sebenar.
